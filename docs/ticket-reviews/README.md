# 티켓 리뷰 기록 운영 규칙

`docs/ticket-reviews/`는 티켓 계획이 확정되기까지의 리뷰 왕복을 압축해 보관한다. 티켓은 계획만
보존하고, 이 디렉터리는 어떤 지적 때문에 계획이 바뀌었는지를 기록한다.

## 목적과 범위

- 리뷰 기록은 대응하는 티켓과 파일명이 같고 디렉터리만 다르다.
- 라운드별 프롬프트와 응답 원문은 커밋하지 않는다. 로컬 작업물은 `.plan-review/`에만 둔다.
- 주요 지적, 반영·부분 반영·미반영 판정과 사유, 사용자 코멘트, 미해결 항목만 기록한다.
- 표현 리뷰는 건수만 기록하고 개별 항목을 나열하지 않는다.

## 형식

```markdown
# <ticket-name> 리뷰 기록

## Phase A (N라운드)

- [B1] <지적 한 줄> → 반영: <결과>
- [S2] <지적 한 줄> → 미반영: <사유>
- 사용자 코멘트: <있으면>

## Phase B (N라운드)

- 표현 리뷰: NITPICK N건 반영 (오타·용어·형식)

## 미해결로 남긴 것

- <항목> (사유)
```

## 제약과 관례

- 리뷰 기록은 해당 티켓의 리뷰가 끝나는 시점에 한 번 만들고 이후 수정하지 않는다.
- 티켓 없이 리뷰 기록만 만들지 않는다.
- 본문은 한국어로 쓴다. 미반영 판정에는 반드시 사유를 적는다.
