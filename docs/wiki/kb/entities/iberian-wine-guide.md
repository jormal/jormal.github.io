# 이베리아 여행 도시별 와인 노트

## 위치와 공개 범위

`info/plan/iberian-passage-2026/index.html`의 `#wine` 섹션에 둔다. 사용자가 암호 없이 볼 수 있기를
명시적으로 요청했으므로 공개 영역에 두며, 날짜·숙소·예약 같은 일정 정보는 넣지 않는다. 도시 순서는
공개 일정과 같은 Madrid → Porto → Lisbon → Sevilla → Granada → Barcelona를 따른다.

## 구성

- 취향·예산 기준은 개인 정보이므로 공개 페이지와 이 문서에 두지 않고, 암호화된 계획 원칙
  (`principles.enc.json`)의 "와인 취향" 항목에만 둔다. 공개 페이지에는 원문 가이드의 구매 우선순위만 남긴다.
- 도시별 `<details>`(기본 접힘): 요약에 추천 품종·와인 수·가격대·대표 와인을 보이고, 펼치면 추천 품종
  카드와 후보 와인 표를 보인다. 표는 종류별로 묶고, 묶음 안은 대표 추천 먼저·가격순이다. 모바일에서는
  행을 사진+텍스트 카드로 바꾸고 병합 셀은 묶음 라벨로, 빈 칸은 숨긴다.
- 기념 구매 후보는 도시 접기 밖에 도시별 병합 셀 표로 한 번 더 보인다. 개수 기준은 암호화된 계획 원칙을
  따른다. 빠진 후보는 지우지 않고 도시별 목록에 남긴다.
- 후보 표 열은 종류(병합 셀)·사진·와인·품종·가격·도수·추천 이유·특징이다. 와인 이름 아래 `추천 빈티지`는
  현지 매장에서 살 수 있는 연도 중 2026년 11월에 마시기 좋은 해다. 생산자 자료·산지 작황 평가·평론 시음
  적기를 근거로 고르며, 신선한 스타일은 `최신`, 무빈티지는 NV로 적는다. 14% 이상은 `주의`를 붙인다.
- 후순위·제외 와인도 같은 열 구조로 기초 정보와 제외 이유를 두고, 정보·사진 출처는 보조 접기 블록으로 둔다.

## 후보 기록 규칙

- 원문 가이드의 와인은 선택되지 않아도 지우지 않는다. 취향에서 벗어난 와인은 후순위·제외 목록으로
  옮긴다.
- 가격은 750ml 현지 소매가 참고 범위만 가격 칸에 두고, 특별 시음·기념 구매·가성비·육류용·한 잔만 같은
  성격은 태그로 분리한다. 확인하지 못한 값은 `—`로 두고 표 위 안내문에서 한 번만 설명한다.
- 가격·추천 품종·대표 추천 도수는 원문 PDF를 우선하고, 표의 품종과 비어 있던 도수는 생산자·판매처 페이지로
  확인해 출처 목록에 남긴다. 검색 요약으로만 확인한 값은 `(일부 검색 요약)`으로 표시한다.

## 사진

- `wine/<slug>.jpg`(높이 최대 720px)와 `wine/thumb/<slug>.jpg`(높이 200px)를 둔다. 여백을 잘라내고
  흰 배경에 합성한 JPEG이며, 썸네일은 원본 사진으로 링크한다.
- 출처는 섹션의 사진 출처 목록에 와인별로 기록한다. 원문 PDF에 실린 이미지는 "원문 가이드(PDF) 수록
  이미지"로 표기한다. 하프 보틀·다른 빈티지 라벨처럼 실물과 다를 수 있는 점도 함께 적는다.
