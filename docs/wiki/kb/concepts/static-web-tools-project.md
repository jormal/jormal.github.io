# 정적 웹 도구 프로젝트

## 개요

이 저장소는 GitHub의 정적 호스팅을 이용해 브라우저에서 작동하는 여러 도구를 제공하는 정적 웹 페이지 프로젝트다. 핵심 산출물은 서버 런타임에 의존하지 않고 사용자의 브라우저에서 실행되는 웹 도구들이다.

## 방향성

- GitHub Pages 또는 GitHub의 정적 호스팅 흐름에 적합한 형태로 구현한다.
- 브라우저에서 직접 사용할 수 있는 도구를 중심으로 기능을 추가한다.
- 기본 배포 단위는 정적 파일이다.
- 서버가 필요한 기능은 기본 전제로 두지 않는다.
- 도구별 화면과 로직은 정적 웹 환경에서 유지보수하기 쉬운 구조로 구성한다.

## 구현 원칙

- 정적 호스팅에서 바로 동작하는 HTML, CSS, JavaScript 기반 구현을 우선한다.
- 빌드 도구를 도입하더라도 최종 결과물은 정적 파일로 배포 가능해야 한다.
- 브라우저 호환성, 접근성, 반응형 레이아웃을 고려한다.
- 외부 서비스나 네트워크 의존성이 필요한 경우에는 해당 의존성과 실패 시 동작을 명확히 한다.
- 사용자 데이터가 브라우저 안에서 처리되는 도구는 저장 위치, 보존 범위, 개인정보 노출 가능성을 명확히 설계한다.

## 배포와 비공개 원본

- `main` 푸시와 수동 실행 시 `.github/workflows/deploy-pages.yml`이 정적 사이트 검증 뒤 GitHub Pages에 배포한다.
- GitHub Pages 설정의 게시 원본은 `GitHub Actions`로 선택해야 한다.
- `private/`는 Git에서 제외하며, 평문 계획 원본처럼 배포하면 안 되는 파일을 둔다. 정적 사이트 검증도 이 디렉터리를 검사하지 않는다.

## 영향 범위

- 새 기능은 정적 웹 페이지에서 접근 가능한 도구 형태로 설계한다.
- 저장소 설정은 GitHub 호스팅과 로컬 정적 웹 개발 흐름에 맞춘다.
- 개발 환경은 JetBrains IDE와 VS Code 사용을 전제로 둘 수 있다.
