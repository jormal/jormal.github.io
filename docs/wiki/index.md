# 위키 색인

## 개념

- [정적 웹 도구 프로젝트](kb/concepts/static-web-tools-project.md) - 이 저장소가 GitHub 호스팅 기반 정적 웹 페이지에서 브라우저 실행 도구들을 제공한다는 프로젝트 방향성을 정리한다.
- [비공개 여행 일정의 단계적 구체화](kb/concepts/private-itinerary-planning.md) - 공개 가능한 여정 초안과 암호화된 상세 일정을 분리하고, 취향 질문으로 여행을 구체화하는 방법을 정의한다.

## 엔티티

- [여러 계획을 분리하는 정보 구조](kb/entities/plan-index-structure.md) - `info/plan/` 인덱스와 계획별 하위 경로를 분리해 공개 초안과 비공개 상세 정보가 섞이지 않게 하는 규칙이다.
- [암호화된 일정 데이터 발행 방식](kb/entities/encrypted-itinerary-payload.md) - 비추적 평문을 AES-GCM 암호문으로 발행하고 브라우저에서 비밀 구문으로만 여는 흐름을 정의한다.
