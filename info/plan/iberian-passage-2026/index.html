Spain / route context

후보 도시를
지도에서.

세비야·론다·그라나다는 안달루시아 축에 있고, 발렌시아와 마요르카는 동쪽 지중해 축에 있습니다. 현재 추천안은 포르투갈을 먼저 지난 뒤 세비야에 2박하고, 론다를 거쳐 그라나다에서 1박한 뒤 바르셀로나로 직항합니다.

현재 추천 경로

Madrid → Porto → Lisbon → Sevilla → Ronda → Frigiliana → Nerja → Granada → Barcelona

별도 축: Valencia·Mallorca는 포르투갈 일정을 줄이거나 빼고 지중해 중심으로 갈 때 비교합니다.

장점 두 번의 야간버스로 낮 시간을 지키고, 마드리드로 되돌아가지 않습니다. 렌터카 수령·주차·반납 없이 론다·프리힐리아나·네르하와 알함브라를 잇고, 바르셀로나 4박을 지킵니다.

단점 버스에서 두 번 자고 도시간 항공을 한 번 이용합니다. 이동 투어의 최소 출발 인원·도착 시각과 알함브라 뒤 항공편의 연결을 예약 전에 확인해야 합니다.
